# Overtonium 1.11.1

A 32-partial additive synthesiser laid out like a 32-channel mixer. Every channel is one sine oscillator locked to a harmonic of the played note, and every channel has its own tuning, envelope and modulation.

## What is fixed in 1.11.1

**Four controls read to seven decimal places.** The pitch modulator's rate and depth, the drift and the amplitude modulator's rate had no text of their own, so a host's automation lane showed `4.0000005 Hz` for four and `1200.0000000 ct` for the deepest pitch modulation. The panel's value popup takes its text from the same place, and so does a screen reader, so the knob said it too while you turned it. They now read as the other controls do: rates to hundredths below 10 Hz and tenths above, `4.00 Hz` and `30.0 Hz`, and cents to tenths below 10 and whole cents above, with nought reading `0 ct`.

Only the text changed. The ranges, the defaults and every stored value are as they were, so sessions, presets and automation play back exactly as before.

A test now reads every parameter at both ends, in the middle and at its default, and fails if any of them prints five or more decimal places, so a control added without its own text is caught before it ships.

## Upgrading

Install over the top. Sessions, presets, automation and window sizes are unaffected, and nothing about the sound has changed.

## Windows will warn you

The Windows installer is not signed, so SmartScreen says the publisher is unknown. Choose "More info" and then "Run anyway". If you would rather not, build from source: the readme says how, and it takes one CMake command.

## macOS

The installer is signed and notarised, so it opens without a warning. It asks which of the three formats you want and installs only those.
