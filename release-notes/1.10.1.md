# Overtonium 1.10.1

A 32-partial additive synthesizer laid out like a 32-channel mixer. Every channel is one sine oscillator locked to a harmonic of the played note, and every channel has its own tuning, envelope and modulation.

## What is fixed in 1.10.1

**Removing the plugin could hang the host.** In a host that unloads the plugin binary once no instances of it are left, taking the last one out could lock the host up, and the only way out was to end the process. It was reported in FL Studio and in Reaper, while hosts that keep the binary loaded were never affected.

The texture the panels are drawn with is an image, built the first time a window opens and then shared by every window after it. It was being kept for the life of the process, which looks like a saving and is one everywhere except here. Under Windows that image lives on the graphics card, so letting go of it hands resources back to the driver, and keeping it in a static meant that happened while the host was unloading the binary. Windows holds a lock for the whole of an unload, and the driver work that releasing the image needs cannot run until that lock is free, so neither one finishes. The texture now belongs to the windows that use it and goes when the last of them closes, with the host running normally and nothing left to release at unload.

If you never opened Overtonium's window in a session, you will not have seen this, because the texture is only built when a window first paints.

Nothing else changed. There is no reason to update if you have not run into it, and no reason not to.

## Upgrading

Install over the top. Sessions, presets and window sizes are unaffected, and nothing about the sound has changed.

## Windows will warn you

The Windows installer is not signed, so SmartScreen says the publisher is unknown. Choose "More info" and then "Run anyway". If you would rather not, build from source: the readme says how, and it takes one CMake command.

## macOS

The installer is signed and notarised, so it opens without a warning. It asks which of the three formats you want and installs only those.
