# Overtonium 1.6.0

A 32-partial additive synthesiser laid out like a 32-channel mixer. Every channel is one sine oscillator locked to a harmonic of the played note, and every channel has its own tuning, envelope and modulation.

## What is new in 1.6.0

**Both modulators pick a waveform.** Pitch offers eight shapes and amplitude seven, on every one of the thirty-three channels. Sine, triangle, sawtooth, reverse sawtooth, square, sample and hold, and a smooth random glide, with pitch also taking a unipolar square that only bends upward.

Per channel is the point. One global LFO could not gate the fifth partial while the fourth breathes, and this is an instrument where every other control is already per partial. The shape sits above the rate on the strip, drawn as a small picture of the wave rather than named: a strip is 38 pixels across, which is about three characters and nowhere near "Reverse Sawtooth". Click it for the list by name.

Amplitude has one square rather than two, because a tremolo only ever comes down from the fader and there is nowhere for a unipolar shape to go that a bipolar one does not already reach. LINK cannot reach the shapes either, since it drags a value across the series along a weighted curve and half a sawtooth is not a shape, so the shape menu offers to set every channel at once instead.

**The pitch depth reaches an octave**, which is for the shapes that step rather than sweep. A square on the pitch is a trill and sample and hold is a run of random notes, and both are worth having at a real interval rather than a vibrato's worth of one. At full depth the bipolar square jumps an octave either side of the note and the unipolar one an octave up. The bottom of the knob is where it was: both the old and new ranges reach 25 cents at half travel, and what used to be the whole range now ends at about three quarters.

**The tuning digits and the shape glyph are lit.** Both sit on the same softly lit ground rather than the flat recess every other control uses, and the waveform traces in the same colour the digits light in, drawn so it blooms. A strip has two displays now rather than a screen and a label.

**Two more factory presets, twenty-eight in all.** _Stepped_ is a slow pad that will not hold still: seven partials trill on squares set to whole intervals, two at a fifth and five at an octave, two more slide back down a fifth on reverse sawtooths, and the top three take their level from sample and hold. _StyloPoly_ is voice 3 of a Dubreq Stylophone S-1 with the vibrato on, thirty cents at six hertz across the series, polyphonic as the original is not, with every partial's level wandering on a smooth random contour of its own.

## Fixed

**Loading a preset told the host about a thousand parameter changes, most of which were not changes.** A preset is written as a neutral base plus the rows that differ, so most parameters were decided twice and both writes were reported. Nothing checked whether a parameter was already at the value being asked for either, so loading the preset already loaded reported all 781 as having moved.

Values are now collected and sent once, skipping anything already there. Cathedral falls from 1029 parameter changes to 226, auditioning ten presets from 11,365 to 4,411, and reloading the current preset from 1174 to none at all. With this many parameters a host's per-parameter bookkeeping is not free, and it was being given three times more of it than there was any reason to.

## Upgrading from 1.5.0

Patches and presets load unchanged and sound identical. Every shape defaults to sine, which is what both modulators have always been, and the amplitude reads its shape a quarter turn ahead so a tremolo still begins at full level and dips.

**The factory presets are renumbered**, since the two new ones sort into alphabetical place rather than onto the end. A session that stored a preset by number opens on a different one. The sound is stored with the session either way, so nothing changes underneath you, but the name shown may not be the one you saved.

**Automation is unaffected.** There are 65 more parameters, 781 in all, and they are inserted among the existing ones rather than appended. Both the Audio Unit and the VST3 identify a parameter by its name rather than its position, so anything already automated stays pointed at the same control.

## Installing

The [install page](https://benjamindehli.github.io/overtonium/install/#downloads) has a row per file saying who each one is for. In short: take the installer for your platform, or the zip beside it if you have no administrator rights or keep plugins somewhere of your own.

| Platform | Installer              | Formats                      |
| -------- | ---------------------- | ---------------------------- |
| macOS    | `.pkg`, with a chooser | VST3, Audio Unit, Standalone |
| Windows  | `.exe`                 | VST3, Standalone             |
| Linux    | none, use the zip      | VST3, LV2, Standalone        |

The macOS build is a universal binary and runs on both Apple Silicon and Intel. Logic and GarageBand only look for new Audio Units when they start, so restart them after installing.

On Linux the zip's contents go in `~/.vst3` and `~/.lv2`.

If you installed an earlier version with the package, the installer replaces it. A plugin folder holding two copies of Overtonium is worth tidying: macOS registers one of them and the host uses whichever that is, which need not be the newer.

## What has actually been tried

All three platforms are built on every push, run through both test suites, and put through pluginval at strictness 8. The VST3 also goes through Steinberg's own conformance validator, and both suites run again under the address and undefined behaviour sanitizers. macOS is the only platform where the plugin has been loaded into a real host, where the Audio Unit and the VST3 also pass `auval`. Nobody has run the Windows or Linux builds in a DAW yet, so treat those as untried and please open an issue with whatever you find.

## Windows will warn you

The Windows installer is not signed, so SmartScreen says the publisher is unknown. Choose "More info" and then "Run anyway". If you would rather not, build from source: the readme says how, and it takes one CMake command.

## macOS

The installer is signed and notarised, so it opens without a warning. It asks which of the three formats you want and installs only those.
